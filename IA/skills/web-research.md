# Skill — Web Research

Recherche web avec traçabilité des sources.

## Procédure
1. Clarifier la requête (scope, dates, sources fiables).
2. Rechercher, prioriser les sources autorité.
3. Pour chaque fait : distinguer **évidence** (URL) / **interprétation**.
4. Rédiger une note dans `/mémoire/<agent>/projets K/AAAA-MM-JJ-titre.md`.

## Contraintes
- Conserver les URLs sources à la fin de la note.
- Ne pas inventer de sources.
- Citer le chemin retourné dans le rapport.
